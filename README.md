## 対応範囲
**戦績サイトなどを作る時に必要になるような資源** が基準

チャンピオン画像や、サモナースペルのID等情報と画像のセット、アイテムのID等情報と画像のセット　など

その他にはランクのアイコンやサモナーのアイコン、ドラゴンやバロンのアイコン

それ以外に欲しいものあったら言ってください  
他の人も欲しそうなデータなら追加します

### これってなんでないの？
大体CommunityDragon自体にない（かなり頑張って探したが、、、）  
新しいものは結構ないです　下にも書くけどアタカンとか

そもそもCommunityDragonにあるものは大体[ここ](https://github.com/CommunityDragon/Docs/blob/master/assets.md)に書いてあります  
それにあるものでしたらすぐに追加できます

### ないもの代表例
2025/05/10現在  
* アタカン関連
  * ミニマップアイコンはあったが、スコアボードにあるようなアイコンはない
* ヴォイドグラブ
  * アタカンと同様
* 一部のドラゴン
  * 大昔から変更されてない箇所が多々　エレメンタルドラゴン(火、水、風、土)の時代のまま

そもそもクライアントにない 試合履歴見てもらうとわかる  
大昔から変わってない  
ケミテックドラゴンとかへクステックドラゴンとかはノーマルドラゴンみたいなアイコンで表現されてる  
アタカンに至っては、そもそもタイムラインに表示されていない まじで倒したタイミングもわからない状態  

意味わからない配置変更と化する前に試合履歴直せ
